# キッズタイマー

保育園や親子イベント向けの、画面が大きく見やすいカウントダウンタイマーです。ビルドは不要で、ブラウザだけで動きます。

## 使い方

1. 上のプリセット（10秒 / 30秒 / 1分 / 3分 / 5分）で時間を選ぶ。好きな長さは「じかんの指定」から設定できます。
2. **スタート** でカウントを開始、もう一度押すと一時停止します。
3. **つぎへ** で同じ設定時間に戻します（次のチーム・次の種目向け）。
4. **おとの設定** で、0秒のおしまい音の種類と音量を変えられます。会場のスピーカーで鳴らす前にテストできます。

残り5秒からは短い音が鳴り、0秒になるとおしまい音がループします。スタート／ストップ／つぎへで止まります。時間になると紙吹雪も出ます。

## 開き方

いまは合成音（Web Audio）だけなので、`index.html` をブラウザで開いて使えます。

MP3 の音声ファイルを足したあとは、`file://` だと音が読めないことがあります。そのときは次のいずれかでフォルダをサーバーとして開いてください。

```bash
python -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。Cursor や VS Code の Live Preview でも同じです。

音は、スタートなどユーザー操作のあとで鳴ります（ブラウザの自動再生制限のため）。

## フォルダ構成

```
simple-event-timer/
  index.html          # 画面のマークアップと Tailwind の設定
  css/styles.css      # カスタム CSS
  js/audio.js         # 音（いまは合成音。将来 MP3 もここ）
  js/confetti.js      # 紙吹雪
  js/timer.js         # カウントダウン本体
  js/main.js          # モーダルと初期化
  assets/sounds/      # 将来の MP3 置き場
  README.md
```

assets/sounds/

音量スライダーは合成音と MP3 の両方に効かせる予定です。

## 技術メモ

- スタイルの大半は Tailwind CSS CDN。フォントは Google Fonts（Inter / JetBrains Mono）。
- カスタムテーマ（アニメーションなど）は `index.html` 内の Tailwind 設定に残しています。
- JavaScript は ES modules にしていません。`file://` でもスクリプトが読み込めるようにするためです。
